# Nov 3, 2026 Update: Event Theme, Rally Info, and Component Safeguard

The update list may change:

- **Amusement Park Defense** gains a new event theme that rotates with the existing theme.
- The **War** interface now refreshes automatically to show the latest Rally information.
- Stack limits increase for some Inventory items, including Computational Components.
- When enhancing Flagship Components, the game asks for confirmation if selected materials include Legendary-quality components. Review the selection before confirming to avoid consuming them accidentally.
- **Planet Miner** will be tested on select servers. Purchasing and using event items gives a chance to obtain Stellar Fragments. Check the in-game event panel to see whether your server is included.

Source: [Murpo reproduction of the official update notes, with a link to the original Discord announcement](https://murpo.com/news/klara-patch-notes-69237bdf7e0e3f5cef39).
