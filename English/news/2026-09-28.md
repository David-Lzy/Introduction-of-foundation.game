# Interstellar Migration update and Shared Moonlight closeout

- **Before migrating servers, claim and redeem every Shared Moonlight reward.** Migration during the event overlap may reclaim event items early—including Full Moon Coins and New Moon Coins—and may affect other events. Finish the event rewards before you move; confirm the event window for your server in-game.
- **Migration slot allocation:** servers in the same Migration Group now share allocations of **3 / 8 / 80 / 80** across the four Migration Power tiers, regardless of server strength. This change also applies to future Interstellar Migration events. Current Migration Power tiers remain unchanged; consult the in-game event page when the event opens for that round’s tier and slot details.
- Server Power calculation still includes Rooms, Technology Research, Combat Craft production, Champions, Flagships, Flagship Components, Crew, Echo Hub, and Champion Weapons; inactive accounts are excluded. The team plans to make future event information available in-game for longer, but timing is not confirmed.
