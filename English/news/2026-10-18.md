# October 17 Fix: Champions Unable to Move During Combat

The official announcement says a fix has been deployed for some players who could not move Champions during combat after the latest update. If affected:

1. Fully restart the game.
2. Download and install the latest game update, then check whether movement works in combat.

The announcement does not specify affected platforms, version numbers, or the full scope of affected players.

Sources: [Official Foundation Discord announcement](https://discord.com/channels/1275441685031157902/1450141757508554877/1560490437008039977); [Murpo transcription](https://murpo.com/news/klara-known-issues-7b95b3a01bd53613cbbc) (October 16, 2026).
