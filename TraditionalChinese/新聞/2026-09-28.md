# Interstellar Migration 更新與 Shared Moonlight 收尾提醒

- **遷服前先領取並兌換 Shared Moonlight 的全部獎勵。** 活動與遷服重疊期間，遷往其他伺服器可能導致活動道具提早回收，包括 Full Moon Coins、New Moon Coins，也可能影響其他活動。遷服前先完成獎勵領取，並在遊戲內確認本服活動時間。
- **遷服名額分配：**同一 Migration Group 內各服現在共用四檔 Migration Power 名額，依序為 **3 / 8 / 80 / 80**，不再按伺服器強度調整；此規則也適用於之後的 Interstellar Migration 活動。本輪 Migration Power 檔位維持不變；每輪具體檔位和名額請在活動開啟後查看遊戲內活動頁面。
- Server Power 計算仍包括 Rooms、Technology Research、Combat Craft production、Champions、Flagships、Flagship Components、Crew、Echo Hub、Champion Weapons；不活躍帳號不計入。開發團隊計畫讓未來活動資訊在遊戲內顯示更久，具體時間尚未確認。
